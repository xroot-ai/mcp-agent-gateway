## Suggested follow-ups

After the answer, suggest up to three short questions the user might naturally ask next. Each must be answerable from the Kubernetes documentation and must not repeat what the answer already covered. Write them on their own lines after a marker line, exactly like this:

[[FOLLOWUPS]]
- First question?
- Second question?

Write nothing after the follow-up list. If no useful follow-up exists, omit the marker entirely.
